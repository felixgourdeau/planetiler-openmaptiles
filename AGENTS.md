# Repository instructions

These instructions apply to `planetiler-openmaptiles` only.

- Do not add, restore, or run unit tests in this repository.
- Do not introduce unit-test frameworks, dependencies, or test harnesses.
- Do not run repository typechecks, including TypeScript `tsc` checks.
- Use source review and diff checks for routine verification. Report any manual
  archive or rendering checks that remain unperformed.
- Preserve Outmap's custom generated mappings and schema constants. Do not run
  upstream regeneration until a preservation approach has been agreed and applied.
